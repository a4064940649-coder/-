- XQ 選股回測可以設「每月換股、依輸出欄位排序取前 N 檔」的話，直接用，`OnlyRebalDay` 留 0。

## 5. 跑 XQ 回測時請特別檢查的五件事

1. **財報有沒有偷看未來。** 02、04 用到季報和年報 EPS。如果 XQ 回測在季末當天就把財報當成已知（實際要一兩個月後才公告），研究中心估計每年報酬會被灌高 2～4pp。
2. **月營收的時點。** 月營收每月 10 日前公告。01 用 11 日以後換股就是為了這個。
3. **有沒有含下市股。** 回測股票池如果只有現在還活著的股票，結果會偏高。
4. **成交值門檻。** 01、08 的預設是 60 日均成交值 ≥ 1 億。「成交值前 300 名」這條線各年差很多：2012 年約 2,200 萬、2019 年約 3,700 萬、2021 年約 1.9 億、2026 年約 2.7 億。回測早年時把 `MinAvgValue` 調低（例如 3000），否則會選不到股票。
5. **拿掉最賺的 5 筆再看一次。** 研究中心的經驗是，這類策略的獲利常常集中在少數幾筆。拿掉後如果就輸 0050，代表靠的是運氣。

## 8. 月營收驚奇 SURGE（2026-11-15 新增；目前研究中心回測最好的選股策略，獨立重算中）

| 項目 | 內容 |
|---|---|
| 腳本 | `12_月營收驚奇SURGE_選股.xs`（進場）；`13_月營收驚奇SURGE_出場_近似.xs`（XQ 不能設每月換股時才用） |
| 白話規則 | 每月營收公布後，算每檔「這個月營收比去年同月多出來的金額，比它自己過去兩年的常態多了幾個標準差」，買最高的 10 檔，抱到下個月再換 |
| 公式 | SURGE ＝（本月年增金額 − 過去 24 個月年增金額的平均）÷ 過去 24 個月年增金額的標準差 |
| 股池 | 上市；60 日均成交值 ≥ 1,000 萬；收盤 ≥ 10 元 |
| 換股 | 每月 11 日以後的第一個交易日算，隔天開盤買賣；不停損 |
| 研究中心回測 | 2019 年起每年 **42.8%**（0050 同期 28.9%）；2015-07 起每年 **31.4%**（0050 21.1%）；最大回撤 **−47.9%** |
| 壓力測試 | 成本加倍後 2019 年起 37.1%；拿掉最賺 5 筆後 40.2%；前後兩段都高於 0050 |
| 交易統計 | 887 筆（一年約 84 筆）；勝率 49.9%；平均賺 15.42%、平均賠 7.29%；每筆期望值 ＝ 49.9% × 15.42% − 50.1% × 7.29% ＝ +4.05%；平均抱 26 個交易日 |

獨立重算後的結論（2026-11-15）：

| 項目 | 數字 |
|---|---|
| 重算結果 | 2019 年起每年 42.95%，和上面的 42.8% 對得上 |
| 實際下單比較可能的範圍 | 2019 年起每年 **25%～36%**（0050 同期 28.9%）。上面的 42.8% 成本算太輕 |
| 滑價的影響 | 每邊多 0.1%，每年約少 2.4 個百分點；每邊多 0.55% 就和 0050 打平 |
| 進場時間的影響 | 晚 1／3／5／10 個交易日進場 → 43.0%／39.8%／38.0%／27.9%。越晚越差 |
| 獲利集中度 | 最賺 10 筆占獲利 44.6%；完全不買這 10 檔還有 31.3% |
| 近期 | 2024 年起每年 42.0%，0050 是 54.5% |
| 改成固定抱 20 個交易日 | 38.9%，最大回撤 −38.7% |
| 改成買 20 檔 | 37.2%，最大回撤 −39.5% |

操作上要注意：
1. **營收一公布就要盡快進場。** 不要拖，晚 10 個交易日優勢就沒了。
2. **用限價單，別追高。** 每邊滑價超過 0.5% 就白做。
3. KY 股研究中心沒有營收資料、沒測到；在 XQ 選股結果裡出現 KY 股時，先排除，才和回測一致。

在 XQ 要確認：欄位名「月營收」能不能用；回測時營收公布前不會偷看；回測從 2016-02 以後看。
