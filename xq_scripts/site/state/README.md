## 實際下單方式與逐筆對帳（2026-11-16，S37 執行研究）
- 換股日隔天 08:30～09:00 送**整股 ROD 限價單**參加 09:00 開盤集合競價（＝回測成交價）。
- 買進限價掛「**漲停價下一檔**」；賣出掛「**跌停價上一檔**」。集合競價是單一價格成交，掛寬不會成交更差。
- 開盤漲停買不到：**當天放棄，09:00 開盤沒成交就立刻刪單**（ROD 單會繼續掛著，盤中打開時會在高價成交，那不是回測的做法），不追、不補（10 年約 4 次）。開盤跌停賣不掉：同樣**立刻刪單**，隔天開盤再掛。（S37 已獨立複製確認）
- 零股不參加整股開盤集合競價，盡量用整股；零股另記一列。
- 每筆記在 state/fill_log_template.csv 的格式（45 欄）；每月研究中心用「成交價相對開盤」算實際滑價，三個月平均每邊 > 0.3% 就調整回測預期（每多 0.1% 約 −0.9 個百分點／年）。
- 資金 3,000 萬以上要分日下單，回測不能直接套用。
