# XQ 回測步驟：現行策略（20＋21 號）

> 研究中心沒有 XQ，下面的選單名稱是一般說法，**實際名稱以你的 XQ 畫面為準**。哪一步找不到、或編譯報錯，把畫面文字或錯誤訊息貼給我，我馬上改。

## 0. 要用的兩支腳本

| 用途 | 檔案 |
|---|---|
| 進場（選股） | `20_月營收驚奇SURGE_已在漲_選股_可調版.xs` |
| 出場 | `21_月營收驚奇SURGE_寬出場_可調版.xs` |

其他腳本（01～19）是舊版本，**不要用**。

## 1. 把腳本放進 XQ

1. 打開 XQ 的 XScript 編輯器，新增一支**選股腳本**，名稱取「SURGE進場」。
2. 把 20 號檔案的全部內容貼上，按編譯。
3. 再新增一支腳本，名稱取「SURGE出場」，貼上 21 號全部內容，按編譯。
   - 21 號寫法和選股腳本一樣（條件成立時 `Ret = 1`）。如果你的 XQ 回測要求出場條件用另一種腳本類型（例如警示腳本、交易腳本），告訴我類型名稱，我改寫。
4. 編譯失敗：把錯誤訊息和行號貼給我。最可能出問題的是欄位名「月營收」。

## 2. 確認參數（都是預設，不用改）

| 腳本 | 參數 |
|---|---|
| 20 號 | `MinSurge` 2.5、`MinRet20` 10、`UseMA60` 1、`RebalDay` 11、`OnlyRebalDay` 1 |
| 21 號 | `ExitSurge` 2.0、`UseMA60` 1、`RebalDay` 11 |

⚠ 20 號 `MinSurge` 一定要是 2.5。舊版預設是 0，會變成另一個策略（平均持 9～10 檔，報酬和回撤都大很多）。

## 3. 回測設定

| 項目 | 設定 |
|---|---|
| 資料 | **還原日線** |
| 股票範圍 | **上市**普通股；**排除名稱帶「-創」的**（創新板） |
| 進場條件 | SURGE進場（20 號） |
| 出場條件 | SURGE出場（21 號） |
| 進出場價 | 訊號**隔天開盤** |
| 最多持有 | **10 檔，滿了不買**（新訊號依「SURGE」欄位由大到小優先） |
| 每檔金額 | **目前淨值的 1/10**（⚠ 最重要：不要選「起始資金的 1/10 固定金額」，那樣報酬只剩約 24%） |
| 起始資金 | 70 萬（代表衛星那一塊） |
| 手續費 | 0.1425% × 2.8 折 ＝ 0.0399%，買賣都收 |
| 證交稅 | 賣出 0.3% |
| 滑價 | 每邊 0.3%（研究中心的嚴成本）；想看樂觀情況再跑一次 0.1% |
| 期間 | 2016-01 到現在（研究中心從 2016-02 才有第一個訊號） |
| 空位 | XQ 只能放現金就放現金（研究中心是放 0050，XQ 數字會略低） |

## 4. 跑完應該看到什麼

| 項目 | 研究中心算的 XQ 版（只算衛星、空位現金、70 萬） |
|---|---|
| 2019 年起每年 | 約 **40%**（換起始日約 33%～45%） |
| 最大回撤 | 約 **−32% 到 −34%** |
| 逐年 | 2016 −1.6%、2017 8.4%、2018 −4.0%、2019 7.2%、2020 79.1%、2021 113.5%、2022 −3.2%、2023 14.9%、2024 34%～36%、2025 37%～39%、2026（到 10/22）65.4% |
| 同期 0050 | 2019 年起每年 28.9%，最大回撤 −34.0% |

- 單一年份差 10～30 個百分點是正常的（固定門檻和名次本來就會差）。
- 2019 年起整段差超過約 5 個百分點，才需要查原因。

## 5. 對不上時，照順序查

1. 每檔金額是不是「目前淨值的 1/10」。
2. `MinSurge` 是不是 2.5。
3. 有沒有排除「-創」、是不是只有上市。
4. 是不是用還原日線、隔天開盤成交。
5. 「最多 10 檔、滿了不買」有沒有設；同一天賣出空出的名額能不能當天買。
6. 還是對不上：用 `research/tw_stock_selection/agents/s18_live_list/FINDINGS.md` 第 5 節的方法逐月對名單。

## 6. 跑完把這些給我

- 2019 年起和全期的年化報酬、最大回撤、交易次數、勝率
- 逐年報酬（2016～2026）
- 你用的設定（尤其是每檔金額的算法、滑價）
- 有截圖最好
