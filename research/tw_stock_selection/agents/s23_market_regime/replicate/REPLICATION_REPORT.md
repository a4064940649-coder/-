# S23 市場環境減碼：獨立複製報告

## 結論：成功

所有事前登記、決定判定的數字都重現了，和原研究**完全相同**（差值 0）。這包括 7 條規則的觸發月份與門檻、訓練期 8 設定 × 20 條路徑、凍結規則、驗證期 V1～V4、全期連續、結構下限，以及 MA_HALF 的事後數字。

- 我依 PREREG 的選擇規則自己挑凍結規則，結果同樣是 **BRD_STOP_Q20**（19／20，技術性通過 T0）。
- 判定同樣是**不通過**：T0 過，V1～V4 四條都不過，每一條的過或不過都和原研究一樣。
- 登記的隨機對照（種子 20261116＋i，20 次）逐位數字也相同。另外用別的種子加抽 200 次，方向一致：凍結規則落在隨機分布中段，沒有擇時能力。

事前標準是年化差與回撤差 ≤ 0.3 個百分點算一致，而且判定要相同。實際最大差值是 0，判定也相同。

唯一要指出的是一處**文字標示**問題，數字本身沒錯：FINDINGS 寫「衛星平均只有約 43% 真的持股」。但 43.2% 其實是「股票市值 ÷ **總淨值**」，換成「股票 ÷ 衛星部位（淨值 − 底倉）」是 57.9%。這不影響任何判定。

## 方法（獨立性）

- **沒碰原研究程式**：沒有 import、執行或讀取 s23lib.py、train.py、validate.py、posthoc.py，prep.py 和 prereg_write.py 也沒讀。我只讀了 PREREG.json 的規則文字、FINDINGS.md 的條件，以及原研究輸出的 JSON（data_check、results*），後者只拿來比對數字。
- **自己寫的部分**（rep_s23_lib.py）：
  - 訊號迴圈：列的選取與 F1 定義和 make_signal_s10 相同，4 個位移每一列都 assert 和 info.targets 相同。
  - 環境變數：BRD、BRD3、LMA、MA200。
  - 三種動作：stop、half（ceil(n/2)）、exit（觸發列 X 整列設為 True）。
  - 重新起跑、路徑配對差、改善路徑的判斷、凍結排序、V1～V4、隨機對照。
- **共用引擎**：s20lib → s17lib → s10lib，用到 make_signal_s10、simulate_s10、e50_fix_suspension、seg_dd、top5_share，以及 s2lib.block_from。
- **解讀校準**（第 0 步，還沒算任何報酬）：
  - BRD3 在開頭不足 3 列時，用現有的列平均（min_periods=1）。這樣算出的訓練期 Q20／Q33 是 0.04310124711113451／0.05354530121090945，和 PREREG 寫死的數值逐位相同。
  - 若要求滿 3 列（min_periods=3），會得到 4.42%／5.45%，對不上。
  - LMA 的 Q20／Q33 = 11／14（np.quantile 預設線性插值）。
  - MA200 = E50[k] < 含當日的 200 日平均。
- **資源**：一律 python3 -I -B。第 0 步 49 秒、峰值 1.86GB；主程式 56 秒、峰值 1.42GB。暫存放 scratchpad/s23rep/（約 100MB），結束已刪除。

## 差異與原因

1. **數字差異：無。** 所有能比的數字差值都是 0，而且是逐位相同，不只是在 0.3 個百分點內。原因是引擎共用，而原研究的規則文字夠精確：只有 BRD3 開頭不足 3 列怎麼處理需要校準，我用門檻的逐位一致性定了下來，沒有看報酬。
2. **隨機對照**：我照 PREREG 的描述自寫抽樣（每個種子各自 `default_rng(20261116+i)`，先抽驗證窗 18 個月，再從全期 129 列抽 32 個月），20 次的結果和原研究逐位相同。加抽 200 次後，各百分位會隨種子移動（例如全期回撤差的百分位從 55% 變 35%），但凍結規則一直落在隨機分布的 P10～P90 之內。結論不變：SURGE 廣度沒有擇時能力。
3. **文字標示（不影響判定）**：
   - FINDINGS 的結構原因寫「衛星平均只有約 43% 真的持股（其餘本來就放 0050）」。原研究算的 43.2% 是引擎 stockfrac，也就是**股票市值 ÷ 總淨值**；衛星目標是 70%，所以這個比例的上限約 70%。
   - 若照字面算「衛星部位中真的持股的比例」（股票 ÷（淨值 − 底倉）），2019 起平均是 **57.9%**。
   - 結論方向（衛星有一大塊本來就在 0050，所以減碼的效果有限）不受影響，但描述應改成「股票平均只占總淨值約 43%（衛星部位的約 58%）」。
4. **T0 技術性通過**：我同樣得到 19／20，凍結規則的回撤差中位數只有 +0.003、Calmar 差 +0.0007。「改善」沒有設最小幅度這個設計缺陷，複製結果一致。
