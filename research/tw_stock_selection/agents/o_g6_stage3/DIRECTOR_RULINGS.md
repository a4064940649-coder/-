本文件在任何複製員開工前寫定；之後只能加註，不能改門檻。

## 裁定

1. **紙上與 V7X 四項定義不一致（外國股、百分位分母、營收底表、金融遮罩）**：本階段**照現況凍結**。G6 要驗的是「正式數字能不能被第三方重現」，不是改口徑。統一口徑列為之後的獨立題，另行量測影響；在那之前 G5 加註「紙上與可執行兩條管線定義不同」。
2. **三項程式偏離既有規格文字（V60 補值、vrank 用前值補收盤、表外停牌用最後成交＋14 天）**：SPEC v2 以**程式實際行為**為準凍結。偏離的影響沿用 o20 量到的區間並列（原引擎有利偏誤逐 j 平均 +0.05～+0.06pp、逐 j 最大 0.35pp），不取代正式數字。
3. **停牌順延**：維持程式讀法為規格；不利端讀法由引擎複製員另外並列報告（不是主欄）。
4. **驗收目標**：M1（現行正式）與 M2（全期統一遮罩）都列。M2 複製成功才正式改採 M2。
5. **資料檔**：複製員可使用前幾輪產生的**凍結資料檔**（R_FIX、B1 補回表、events_v2、universe_announce、面板），但不得 import 任何研究員 .py。名單複製員（A）不得讀任何官方名單與目標數字；引擎複製員（B）可讀封存的官方名單做「單獨的引擎比對」，但不得讀目標淨值與目標數字。
6. **盲版規格**：保管員（K）產出 SPEC_v2_blind.md，刪掉所有名單摘要（訊號日數、列數、KY 槽數等可用來反推目標的內容）後才交給 A。
7. **三層比對門檻**（事前寫定）：j 中位數 ≤ 0.1pp 且 t 差 ≤ 0.05；逐 j 平均 ≤ 0.1pp；逐 j 最大絕對值 ≤ 0.2pp。另報中位 j 與最差變體是否換人。名單層：逐槽 Jaccard ≥ 0.99。任何一層不過就列分歧並追到交易／槽位層；揭盲後的修正版只能並列，嚴格版為主欄。

## 角色（不同子代理，由研究中心層直接分派，不得兼任）

- **K 保管員**：用原程式重產 V7X REAL 名單（M1、M2）與目標數字，封存到 `o_g6_stage3/sealed/`（壓縮＋sha256），產出盲版規格。K 不參與複製與裁定。
- **A 名單複製員**：只讀 SPEC_v2_blind 與資料檔，重建紙上與 V7X 的 REAL_{opt,p90,carry} 名單（M1、M2）。
- **B 引擎複製員**：只讀 SPEC v2 與資料檔，自寫 V7X 引擎，在封存官方名單上跑正式各格。
- **C 覆核員**：拿 A、B 的產出與封存目標做三層比對，寫裁定書。
