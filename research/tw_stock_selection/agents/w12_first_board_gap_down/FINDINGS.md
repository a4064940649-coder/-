**為什麼不行**
- 不扣成本時，對等權的毛異常是小幅正數：C 版挑選期 +0.51%（t 0.90），驗證期 +0.34%（t −1.01）。

- 一般交易來回 0.67%、當沖約 0.43% 的成本就把這點毛利吃光了。
- 型態的小幅毛利只存在 2015 年以前，之後消失。

## 規則（事前固定，寫在 results.json 的 PREREG）

**股池**
- 上市普通股（4 碼代碼，排除 91xx）。
- Day0 須在流動性池內：60 日均成交值 ≥ NT$1,000 萬（上市後停牌日記 0、滿 60 筆），且原始收盤 ≥ 10 元。
- Day0 的 flag 必須是 0、1 或 2。
- 先剔除「有值檔數 < 300」的日子（2018-01-13），之後才做任何 rolling。
- 處置股：用 disposal_reconcile 正式版的標準事件表定義（rlib.records：disposal_5y，start 對到第一個 ≥ start 的交易日，end 對到最後一個 ≤ end 的交易日）。Day0 或 Day1 落在處置期間就排除。
  - 名單 2021-09-24 起才有，之前無法排除。
  - 實際只排除到 1 筆（Day1 處置）。
- 全額交割股：沒有名單資料，無法排除（限制）。

**Day0（首板）**
- 收盤漲停的判斷照 w3 lim.py：
  - 參考價 = close_raw / (1+ret)。
  - 漲停價 = 參考價 × (1+漲幅)，依升降單位無條件捨去。漲幅 2015-06-01 前是 7%，之後是 10%；2005-03-01 前用舊制升降單位。
  - 收盤 ≥ 漲停價 − 半檔，且收盤 ≥ 最高價 × 0.999，且 flag ∈ {0,1,2}。
- Day-10～Day-1 都沒有收盤漲停。

**相對位置 rp**
- rp = (adj_Day0 − 60 日最低 adj) / (60 日最高「還原 high」 − 60 日最低 adj)。
- 窗口 Day-59～Day0，含 Day0，至少要有 40 筆。
- 主規格 rp ≤ 0.5。

**Day1 進場**
- g = Day1 還原開盤 / Day0 還原收盤，等於 Day1 開盤 / Day1 參考價，可以避開除權息造成的假缺口。
- 0.96 ≤ g ≤ 0.99 就以開盤價買進。
- 以下情況不買：Day1 無開盤價、Day1 flag 是 3 或 4、Day1 處置、開盤跌停（開盤 ≤ 跌停價 + 半檔；跌停價依升降單位無條件進位）。
- 限制：以開盤價成交，條件也用開盤價判斷，實務上要在開盤撮合後立刻下單。

**出場（三版全部報告）**
- A：Day1 收盤賣（現股當沖）。只算 2014-01-06 起的事件。Day1 收盤跌停時改到 Day2 開盤賣，成本按一般賣出。
- B：Day2 開盤賣。
- C：Day2 收盤賣，作為判定用的版本。
- 出場時點如果無價或處在跌停，順延到下一個價格時點，最多 10 日；已下市就用最後收盤。
- 實際上只有 0～2.4% 的事件被順延或被迫隔夜。

**成本**
- B／C：照 exlib.cost_rates(0.001)。
  - 買 = 0.1425%×0.6 + 滑價 0.1% = 0.1855%。
  - 賣 = 0.1425%×0.6 + 證交稅 0.3% + 滑價 0.1% = 0.4855%。
  - 來回約 0.67%；壓力情境買、賣各 0.5%。
- A：BRIEF 的當沖來回 0.23%，加上滑價每邊 0.1%，共 0.43%。
  - 2017-04-28 以前當沖稅是 0.3%，所以再加 0.15%，共 0.58%。
  - 壓力情境 1%。另報 exlib 費率口徑（約 0.52%）。

**變體與統計**
- 敏感度：
  - GAP_SHALLOW：g ∈ [0.98, 1.00)。
  - GAP_DEEP：g ∈ [0.94, 0.97]。
  - NO_RP：拿掉 rp 濾網。
- 統計：
  - 事件報酬 = 扣成本後減「同區間同池等權」。等權按開→收、收→開分段平均後連乘，同池用前一日判定。
  - 另報對上市等權、對 0050。
  - t 先按進場月份平均，再對月平均做 t。期間以 Day0 日期歸屬。
- 日曆組合：每天等權持有當日在場的事件，沒有事件時拿現金。

**判定規則**
- 主規格 C 版要在挑選期與驗證期都做到：淨異常 > 0 且 t_month ≥ 2，而且組合淨年化 ≥ 0050。
- 兩段都過 → 可用；只過一段 → 待觀察；都沒過 → 不可用。
- 某一段事件 < 30 筆或事件月份 < 24 → 無法測試。
- A／B 只作參考；若 A 或 B 兩段都過而 C 沒過，最多判待觀察。

## 資料核對與限制
- 漲停判斷沿用 w3 lim.py，舊制升降單位已由該組驗證過。官方資料年份「收盤漲停／≥9.5%」約 0.96；src 3 期間約 0.75～0.81，所以那一段另外報告。
- 2019～2023 面板只有存活者，驗證期偏樂觀；即使這樣結果仍然是負的。
- 2024-01-02～2024-02-14 沒有資料。
- 2025-01-21 的 close_raw 是中午價。
- 沒有最低價，所以無法判斷盤中跌停鎖死；跌停一律以開盤價、收盤價判斷。
- 2021-09 以前沒有處置名單，全期間都沒有全額交割名單。這兩類多半已被流動性池擋掉，實際影響很小。
- 成交假設偏樂觀：以開盤價成交，而且條件也用開盤價判斷。真實成交價只會更差，不影響「不可用」的結論。
- 日曆組合的設計是「有事件就全額投入、等權分散」，持股常常只有 1～3 檔，所以回撤很深（−40%～−67%）。這反映的是策略本身的集中度，不是程式錯誤。
- 組合成本全部記在進場日，持有只有 0～2 日，近似誤差很小。
- 沒有修改其他資料夾，也沒有 git commit。所有程式都用 python3 -I 執行，並設定 sys.dont_write_bytecode，不在 w3／exec_rebuild 寫 bytecode。
