## 5. 我們學到什麼

**被支持的機制**
- **處置令確實讓當沖退場**（處置期內 74/74 筆零當沖）。但這是制度事實，不是溢酬證據。
- **處置事件的報酬主要是強勢延續加上散戶熱潮年度的右尾**（H-alt1、H-alt2 得到支持）：
  - 鎖漲停、沒買到的事件事後最強；
  - 溢酬只出現在 2014 年後；
  - 2020、2021、2026 三年占 67%。
- **散戶在 0050 之外每多一條腿，都要先付結構性成本。** 嚴格預收加上 T+2，主欄平均閒置 **26%**；零股價差每邊 0.4%，再加分盤衝擊。扣成本前的 +3.15%，到對 0050、壓力成本時只剩 −0.41%。
- **存活股的歷史股數可以從 GitHub 上的學術複製 repo 補回來**（TEJ 對 goodinfo 差 0.05%）。下市股、減資事件與 2011 年以前的產業別，在只能連 GitHub 的條件下補不回來。

**被否定或下修的機制**
- 「小額現股帳戶在處置期扮演流動性提供者，賺流動性溢酬」：**否定**。預測方向相反（成交值降幅大的組 −3.16pp，t −3.88），2006～2013 年為負，對 0050 加壓力成本後為負。
- 「d0 是主策略低相關的第二條腿」：**否定**。可執行口徑下相關 0.52，2019 年起 0.67；去掉 2021 後仍有 0.42。
- 「2006～2013 的缺口主要來自已下市股」：**下修為「下市股和減資事件漏抓兩者都有」**。
- 「2011～2013 可標近似 PIT」：**撤回**。

**方法教訓（下一輪起寫進 PREREG 範本）**
1. **成本參數不得用驗證期資料校準。** 本輪的最後一盤成交占比用到 2025-09～2026-03，校準後的成本反而比 o9 低。以後要嘛只用挑選期校準，要嘛把校準窗從驗證期切掉。
2. **逐筆門檻要用 0050 當主要基準，並且同時報中位數與「去掉前 5% 後的平均」。** 同池等權在驗證期每窗口落後 0050 1.07pp，用它當基準等於放寬門檻；靠右尾撐起的平均不能當成「典型一筆賺錢」。
3. **多個時點的中位數不是多次獨立證據。** 時點之間相關 0.89～0.965，「9 時點的 p10」不能當穩健性證據；報告時要附上時點間的相關係數。
4. **PIT 覆蓋只能往回看。** 「24 個月內的後續快照」屬於前視；留一檢核必須套用公告時滯，不能用檢核日之後的錨點。
5. **真值只來自存活股時，驗證的也只有存活股。** 閘門要把下市股的誤差分開報。
6. **GitHub 是本環境唯一的資料管道。** 證交所、公開資訊觀測站的原檔，要等使用者在可連官網的環境下載後，放進 `raw/` 才能補。
7. **複製員的 cache 也要算進磁碟紀律**，題目結束時一起刪除（本輪漏了 413MB）。
