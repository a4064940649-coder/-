## 結論：不可用
- 主規格是 BASE 的 C 版（連板持有），挑選期和驗證期都輸。扣成本後，每筆事件對同池等權的異常報酬顯著為負，日曆組合遠落後 0050 和同池等權。
- 不扣成本也賺不到錢：BASE C 毛異常在挑選期 −0.40%（t −1.71），驗證期 −0.23%（t −0.10）。問題不只是成本吃掉利潤，這條規則本身就沒有正的超額報酬。
- 二板沒有比首板強：對照組（首板＋同一套 Day1 規則）挑選期毛異常 +0.11%，二板只有 −0.40%；驗證期兩者都約 −0.22%。
- A／B 版、縮量／放量、三板版本都沒有任何一段通過（variants_pass_count 全為 0）。

## 事前設定（PREREG，看結果前寫入 results.json）
- **股池：** 上市 4 碼普通股，排除 91xx。Day0 的 60 日均成交值 ≥ NT$1,000 萬、收盤 ≥ 10 元、flag ∈ {0,1,2}。Day0 或 Day1 在處置期間就排除（disposal_5y，名單 2021-09 起才有）。全額交割沒有名單資料，無法排除。
- **剔除缺漏日：** 有值檔數 < 300 的日子（2018-01-13）先剔除，再算 rolling。
- **漲停價：** import w3_limitup_pullback/lim.py。漲幅 2015-06-01 前 7%、之後 10%，分段處理；2005-03 前用舊制升降單位。收盤漲停的條件是：收盤 ≥ 漲停價 − 半檔，而且收盤 ≥ high×0.999。一字板的條件是開盤 ≥ 漲停價 − 半檔。
- **Day0（BASE）：** Day0 和 Day−1 都收盤漲停，t−11～t−2 沒有收盤漲停。
- **Day1 進場：** Day1 有開盤價、不在處置，而且開盤 < 漲停價（不是一字板）。另外要求還原開盤 / Day0 還原收盤 ≥ 0.97。符合就以 Day1 開盤價買進。
- **出場：**
  - A：Day1 收盤（現股當沖），只算 2014-01-06 起的事件。
  - B：Day2 開盤。
  - C：收盤漲停就續抱，第一個收盤沒漲停的隔日開盤賣，最多持有 10 日。
  - 開盤或收盤跌停、停牌時順延賣出。
- **成本：**
  - B／C 用 exlib.cost_rates(0.001)：買 0.1855%、賣 0.4855%，來回約 0.67%；壓力情境來回 1%。
  - A：當沖 0.23% 加滑價 0.2%，合計 0.43%；2017-04-28 前當沖稅較高，再加 0.15%。
- **變體：**
  - VOL_SHRINK：Day0 量 ≤ Day−1 量；VOL_EXPAND：Day0 量 > Day−1 量。量 = value / close_raw。
  - THREE_BOARD：連續 3 板，t−12～t−3 沒有收盤漲停。
  - CONTROL_FIRST：首板，t−10～t−1 沒有收盤漲停。

  - 事件淨異常（對同池等權）> 0，且 t_month ≥ 2。

## 資料核對與限制
- **src 3 期間（2024-02-15～2025-09-23）：**
  - 收盤漲停偵測率（收盤漲停數 / 漲幅 ≥ 9.5% 的檔數）只有 0.75～0.81，官方資料期間是 0.96～0.97。二板要連兩天都抓到，漏抓會加倍。
  - 碰到 src 3 的事件：n 206，−0.81%（t −1.36）。
  - 驗證期剔除 src 3：n 900，−0.92%（t −2.63）。結論不變。
- **事件日期集中：** 2008-10-31 有 48 筆、2009-05-04 有 43 筆，集中在少數日子。t 已按進場月份分群處理。
- **極端值：** raw 介於 −21.5%～+50.0%。抽查 6658（2026-04-22 首板、04-23 二板，Day1 開 103 買、連 4 板，05-04 開 154.5 賣，+50%），與原始價核對正確。排除前 5% 後，均值更負（−1.65%／−1.99%）。
- **日曆組合年化為什麼極負：** 同時持有只有 1～2.4 檔，每筆事件約 −1%，每年上百筆事件連續複利，所以年化接近 −45%。作為規則確實不可用；換成較低的單筆資金比例也不會讓報酬轉正。
- **其他限制：**
  - 2019–2023 面板只有存活者，驗證期偏樂觀，即使如此仍為負。
  - 2021-09 前沒有處置名單，全程沒有全額交割名單。
  - 沒有 low 欄，跌停用開盤／收盤判斷。
  - 以開盤價成交、條件也用開盤價；Day1 開盤後立刻下單的實際滑價可能大於 0.1%。
  - 2024-01-02～2024-02-14 無資料。

## 判定
- 挑選期：beat_EW_t2 = False（−1.06%，t −5.82），not_lose_0050 = False（−45.1% 對 +7.7%）。
- 驗證期：beat_EW_t2 = False（−0.90%，t −2.88），not_lose_0050 = False（−42.5% 對 +28.3%）。
- A／B 版也是兩段都沒過，所以沒有升為待觀察。最終判定：**不可用**。
- A 股和日本的二板接力教學，前提是連板溢價和買得到。在台股上市股，二板隔日可以買到的那些股票（非一字板、開盤 ≥ 0.97），平均隔日就回吐；買得到本身就是一種逆選擇，真正強勢、會繼續漲的股票多半開一字板買不到。
