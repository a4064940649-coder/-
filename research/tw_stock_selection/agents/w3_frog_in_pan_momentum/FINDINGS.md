## 結論：不可用

- 主版本 FIP20_LOW_H3 扣成本（滑價 0.1%）後，兩段都沒有贏同池等權到 t≥2，也都輸 0050。
- ID 篩選的方向和論文一致：ID 低半贏 ID 高半，也贏純 12-1 動能。但這個增量每月只有 0.2～0.5 個百分點（t 1.5～1.9），不夠讓組合打敗等權或 0050。

## 事前規則（PREREG 摘要，看結果前固定）

- **訊號日：** 每月最後交易日 d。2018-01-13（全市場只有 46 檔有值）先整列剔除再算位置回看。
- **日報酬：** r = adj 相鄰交易日報酬；flag 3/4/5 的日子設為缺值。
- **計算窗：** r 的位置 i−251…i−21，共 231 日（等於 adj 的 t−252 到 t−21）。有效日至少 200 天才有訊號。
- **PRET：** 窗內 Π(1+r)−1。
- **%pos／%neg：** 分子是 r>0 或 r<0 的天數，分母是有效日（0 報酬日只進分母）。
- **ID：** sign(PRET)×(%neg−%pos)，越低代表上漲越「連續」。
- **股池：** 上市流動股，條件全部要符合：
  - 4 碼代碼，排除 91xx；
  - 60 日均成交值 ≥ NT$1,000 萬，原始收盤 ≥ 10 元；
  - d 當天 flag 為 0/1/2，且不在處置期間（處置名單 2021-09 起才有）；
  - d+1 有開盤價，PRET 與 ID 都有值。
  - 平均股池：挑選期 447 檔，驗證期 624 檔。
- **主版本 FIP20_LOW_H3：**
  - PRET 前 floor(20%×N) 檔中，取 ID 由低到高的前 ceil(一半) 檔（同 ID 時 PRET 高者優先），等權，平均約 51 檔；
  - d+1 開盤成交；
  - 開盤漲停（2015-06 前 7%、之後 10%，容差 0.6%）且該批次未持有時視為買不到，由同排序下一名遞補；
  - 持有 3 個月、3 批重疊：每批 1/3 資金、各自複利，第一個月三批同時建倉。
- **成本：** 用 exec_rebuild/exlib.cost_rates。
  - 主要情境：買 0.0855%＋滑價 0.1%；賣 0.0855%＋證交稅 0.3%＋滑價 0.1%，來回約 0.67%（即 BRIEF 的 0.5% 情境加滑價）。
  - 壓力情境：來回 1%。另報毛報酬。
- **變體：**
  - (a) FIP20_LOW_H1：月換股；
  - (b) FIP10_LOW_H3：PRET 前 10%×ID 低半；
  - (c) FIP20_HIGH_H3：對照組，PRET 前 20% 中 ID 高的一半；
  - (d) FIP20_LOW_H3_MA200：d 收盤加權指數高於 200 日均線才持股，否則全部改持現金。
- **診斷：**
  - MOM20_H3：PRET 前 20% 全買；
  - LOW−HIGH 與 LOW−MOM20 的毛價差；
  - 動能家族直接比較（mlib 股池、日曆、成本）。
- **對手與 t 值：**
  - 同池等權：同股池，d+1 開盤月換股，不扣成本，比扣成本的策略更嚴格；
  - 0050 含息；
  - t 值用日曆月超額報酬。
- **判定：** 主版本挑選期與驗證期都要扣成本後對等權 t≥2，且年化 ≥ 0050，才算可用。

## ID 篩選本身有沒有用（機制診斷）

| 毛價差（每月） | 挑選期 | 驗證期 | 2024～2025 | 2019-05～2023-12 |
|---|---|---|---|---|
| ID 低半 − ID 高半 | +0.35%（t 1.90） | +0.49%（t 1.54） | +0.82%（t 1.38） | +0.32%（t 0.87） |
| ID 低半 − 純動能前 20% | +0.17%（t 1.81） | +0.24%（t 1.51） | +0.43%（t 1.43） | +0.15%（t 0.83） |

- 方向和論文一致：連續、溫和的上漲比少數幾天暴漲更能延續，兩段都是正價差。
- 問題在底子：台股的 12-1 動能本身對等權幾乎是 0（挑選期 t −0.52）。ID 在上面加 2～4%/年，仍然只到「打平等權」的程度。
- 選中股的特徵：
  - 挑選期 ID 平均 −0.084，%pos 49.9%；ID 高半分別是 −0.002 與 46.1%。
  - ID 低半的流動性明顯較大：60 日均成交值中位數挑選期 1.55 億，ID 高半 0.93 億；驗證期 4.28 億對 2.60 億。所以部分價差可能來自偏大型、流動股，而不是純粹的 ID 效果。
- 股池內 PRET 與 ID 的 Spearman 相關平均只有 0.10。全股池 ID 中位數 −0.035。

## 限制

- **只有上市股：** 沒有上櫃，也沒有市值資料，股池只能用成交值與股價篩選。
- **存活者面板：** 2019～2023 面板只有存活者。驗證期存活者段年化 19.5%，等權 17.5%，t 0.57。
- **來源 3 期間：** 2024-02-15～2025-09-23 的收盤是 Yahoo 13:20 近似價，日報酬正負號可能失真，會影響 %pos 與 %neg，進而影響 2024～2025 的 ID。
- **2024 年初缺資料：** 2024-01-02～02-14 無資料，跨缺口的那一筆報酬只算 1 天。
- **第一個訊號窗不足：** 第一個訊號日 2004-12-31 的回看窗只能從 2004-01-02 開始，比規則少約 4 天（仍有 ≥200 個有效日），只影響第一個月。
- **成本口徑：** 主要情境用 exlib 的滑價 0.1%，來回約 0.67%，比字面上的 0.5% 略嚴。壓力 1% 下結論不變：挑選期對等權 t −0.05，驗證期 1.23。

## 判定依據

- 挑選期：對等權每月 +0.05%，t 0.25（未過 t≥2）；淨年化 7.63% 低於 0050 的 7.71%。不過。
- 驗證期：對等權每月 +0.58%，t 1.37（未過）；淨年化 22.92% 低於 0050 的 28.27%。不過。
- 兩段都沒過，判定**不可用**。
- 可留下的研究線索：ID 低半贏 ID 高半的方向在兩段一致（毛價差 t 1.9 與 1.5），但效果小。可以當成動能類訊號的輔助排序，不適合單獨使用。
