### 0.2 正式版選擇規則（依「實盤做得到」選，不看結果）
1. 進場＝處置記錄 start 當日收盤（非交易日順延到下一交易日；start 或持有期落在 2024-01-02～02-14 資料缺口 → 剔除，因為無法驗證成交）。
2. 進場日 ret ≥ 9% → 視為買不到（src=3 期間收盤是 13:20 近似，無法可靠判定「鎖死」，取保守的 9%）；買不到不佔位，同檔之後的新處置記錄仍可在其 start 進場。
3. 延長（merge_known）：持有中，同檔新處置記錄的公告日 < 目前預定出場日 → 出場日延到新記錄最後一天（可連續延長）；公告日 ≥ 預定出場日（首尾相接、出場當天盤後才公告）→ 照原日收盤賣，新記錄當新事件。理由：盤後公告，只有出場日之前公告的才是出場時已知資訊；chain（把首尾相接也合併）用到出場當天盤後才知道的公告，實盤做不到。
4. 出場日 ret ≤ −9% 或無成交 → 延到第一個 ret > −9% 且有價日收盤賣。
5. 成本 0.8% 來回；進場時屬「再處置」（前 30 個交易日內同檔有處置結束）用 1.2%。另報 0.5%／1.2% 敏感度。
6. 流動性：進場前一交易日 60 日均成交值 ≥ 1,000 萬且收盤 ≥ 10（只用已知資訊）。
7. 主要報酬＝個股含息報酬 − 上市流動性合格等權（前一日判定）；另報原始淨報酬、對 0050。主要 t＝t_month（淨額）。
8. 判定：挑選期淨平均 > 0 且 t_month ≥ 2、驗證期淨平均 > 0 且 t_month ≥ 2、去前 5% 後淨平均 > 0 → 可用；只過驗證期 → 待觀察；否則不可用。
