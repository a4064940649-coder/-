# 技術分析組 FINDINGS：經典技術分析扣成本後能否打敗大盤（上市股、只做多現股）

由主研究員依技術分析組回報存檔；完整數字在同資料夾 results.json、results_rules.json、results_composite.json、results_main_filter.json；程式 tlib.py、t1_rules.py～t4_merge.py。

## 結論
- **不可用。** 21 條經典規則（KD、MACD、RSI、布林 3 種、帶量突破 5 種、均線 4 種、K 線 3 種，預設參數、事前固定）在挑選期 2005-01～2019-04 **0 條通過**（門檻：組合淨 CAGR > 0 且對上市等權 t ≥ 2）。t 最高的是帶量突破持 60 日，只有 +0.58。
- 探索用合成（帶量突破 20／60 日）在驗證期 2019-05～2026-10 淨年化 10.8%，輸上市等權 16.3%、0050 28.3%（t −0.81／−1.68）。
- **最差：KD 低檔黃金交叉**，挑選期組合年化 −36.3%（對等權 t −12.7），兩個子期間與驗證期一致為負。
- **主策略技術濾網不採用。** 15 個事前固定濾網只有「加權指數 MACD < 0 時空手」在 2021–23 過關（最大回撤 −24% → −8%），2024–26 年化 65.5% → 22.0%（對原策略 t −2.96）失敗。不買超買（RSI ≤ 70、K ≤ 80）會濾掉主策略的主力股，全期 t 約 −2 到 −3.5。停損與大盤空手型濾網降低回撤，但效果約等於直接少持股，兩期方向相反。
- **重要提醒：** 主策略以日頻計算的最大回撤為 **−35.0%**（2025-04，落在 src 3 期間），比月頻報的 −26.4% 深。日頻引擎不加濾網時年化 49.01%，與原程式 48.98% 一致。

## 為什麼沒用
1. 扣成本前優勢太小：每持有日 −8.5～+1.9 bp。
2. 成本壓垮短線：持有 5–6 日的規則每年成本拖累 24–26%，13–17 日約 8–11%。
3. 超賣類（KD、RSI、布林下軌）扣成本前就是負超額；RSI 勝率 62–74% 是平均持有 100 日以上跟著大盤漲的錯覺。
4. 順勢類勝率 20–35%，扣成本後約等於等權，是較粗糙、換手更高的動能因子；帶量突破只在 2015 年以前略有效（t 1.4），之後轉負。
5. 組合曝險長期接近 100%，2008、2011、2022 都沒躲掉。
